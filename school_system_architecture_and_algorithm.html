02

Technical Algorithm & Logic

Phase A: Dynamic Config Resolution & App Boot 

1. START Application Initialization.
2. Read LocalStorage key: 'CUSTOM_FIREBASE_CONFIG'.
   IF (CUSTOM_FIREBASE_CONFIG != NULL AND isValid(CUSTOM_FIREBASE_CONFIG)):
       activeConfig = JSON.parse(CUSTOM_FIREBASE_CONFIG)
       connectionMode = 'CLIENT_CUSTOM_NODE'
   ELSE:
       activeConfig = DEFAULT_ENV_VARS
       connectionMode = 'SYSTEM_DEFAULT'
3. Execute initializeApp(activeConfig).
4. Instantiate Firestore: db = getFirestore(app).
5. Instantiate Cloud Storage: storage = getStorage(app).
6. Asynchronously fetch initial collections (students, teachers, app_data).
7. Mount React State and Render UI.

Phase B: Regex Auto-Parser & Dynamic Connection 

8. Admin opens Cloud Database Configuration Modal.
9. On Textarea Input:
   rawSnippet = getElementById('swal-db-paste').value
   apiKey = regexExtract(rawSnippet, /apiKey\s*:\s*["']([^"']+)["']/)
   projectId = regexExtract(rawSnippet, /projectId\s*:\s*["']([^"']+)["']/)
   storageBucket = regexExtract(rawSnippet, /storageBucket\s*:\s*["']([^"']+)["']/)
   appId = regexExtract(rawSnippet, /appId\s*:\s*["']([^"']+)["']/)
   
   Populate form fields with extracted tokens.
10. On Click 'Save & Connect':
    IF (apiKey.length > 0 AND projectId.length > 0):
        LocalStorage.setItem('CUSTOM_FIREBASE_CONFIG', JSON.stringify(newConfig))
        LogAudit('Security', 'Database Connected', projectId)
        Trigger window.location.reload()
    ELSE:
        Display validation error.

Phase C: Runtime CRUD & Batch Operations 

11. User triggers data write (e.g. Student Admission / Attendance Save).
12. StoreContext dispatches call to Adapter (supabase.from(table)).
13. Adapter slices dataset into chunks of 450 items (CHUNK_SIZE <= 500).
14. For each chunk:
        batch = writeBatch(db)
        chunk.forEach(item => batch.set(doc(db, table, item.id), item, {merge: true}))
        await batch.commit()
15. If file/photo attached:
        uploadFile(blob, 'student_photos') -> returns HTTPS Cloud URL
        Update student avatar with URL.
16. Return { error: null } to StoreContext.
